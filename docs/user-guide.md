## 1. ภาพรวมระบบ

**I-FAQ Knowledge Base** คือระบบคลังความรู้ภายในองค์กร ประกอบด้วย 2 ส่วนหลัก:

| ส่วน | คำอธิบาย |
|------|-----------|
| **I-FAQ** | คลังบทความ/ความรู้ภายในองค์กร จัดหมวดหมู่เป็น Level 1 และ Level 2 รองรับการแสดงผลแบบ HTML, PDF, และวิดีโอ |
| **File Portal** | คลังเอกสาร PDF และไฟล์วิดีโอจาก Shared Drive ของบริษัท — แสดงไฟล์ตามสิทธิ์ของ AD Group ที่ตัวเองเป็นสมาชิก |

---

## 2. การเข้าสู่ระบบ

### ขั้นตอน

1. เปิด Browser แล้วไปที่ URL ของระบบ (ขอ URL จาก IT)
2. กรอก **ชื่อผู้ใช้ Windows** (ไม่ต้องใส่ `DOMAIN\`) และ **รหัสผ่าน Windows**
3. กด **Sign In**

> **หมายเหตุ:** ระบบใช้บัญชี Active Directory (AD) เดียวกันกับ Windows ของคุณ — ไม่มีรหัสผ่านแยก

### ข้อผิดพลาดที่พบบ่อย

| ข้อความ | สาเหตุ | วิธีแก้ |
|---------|--------|---------|
| `Invalid credentials` | ชื่อผู้ใช้หรือรหัสผ่านผิด | ตรวจสอบให้ตรงกับที่ Login Windows |
| `Account locked` | บัญชีถูก lock จาก AD | ติดต่อ IT เพื่อ unlock |
| หน้าค้าง / ไม่ตอบสนอง | ปัญหาเครือข่าย | รีเฟรชหน้าหรือลอง Browser อื่น |

## 3. หน้าหลัก (Home)

หลัง Login สำเร็จจะเข้าสู่ **หน้าหลัก** ซึ่งประกอบด้วย:

### 3.1 แถบด้านซ้าย (Sidebar)

```
┌─────────────────────┐
│  [Logo NCR]         │
│  I-FAQ Knowledge    │
│  Base               │
├─────────────────────┤
│  ▶ หมวดหมู่ Level 1 │
│    ▶ Level 2        │
│      • บทความ       │
├─────────────────────┤
│  📁 File Portal     │
│    ▶ โฟลเดอร์       │
│      • ไฟล์ PDF     │
│      • ไฟล์วิดีโอ   │
└─────────────────────┘
```

- **หมวดหมู่ I-FAQ** — กดหัวข้อเพื่อขยาย/ยุบรายการ
- **File Portal** — แสดงไฟล์ตาม AD Group ที่มีสิทธิ์

### 3.2 พื้นที่หลัก (Main Content)

- **ช่องค้นหา** — พิมพ์คำค้นแล้วกด Enter หรือปุ่ม Search
- **Featured Knowledge** — บทความที่ Admin เลือก Highlight หรือถูกเปิดบ่อย

## 4. การค้นหาข้อมูล

### วิธีค้นหา

**วิธีที่ 1 — ช่องค้นหาในหน้าหลัก:**
1. พิมพ์คำค้นในช่อง "Search documentation…"
2. กด **Enter** หรือปุ่ม **Search**

**วิธีที่ 2 — กด `/search?q=คำค้น` ใน URL โดยตรง**

### ผลการค้นหา

หน้า Search จะแสดง **2 ส่วน** พร้อมกัน:

#### ส่วนที่ 1: I-FAQ
- ผลลัพธ์จากบทความใน Knowledge Base
- กดชื่อบทความเพื่อเปิดอ่าน

#### ส่วนที่ 2: File Portal
- ผลลัพธ์จากชื่อไฟล์ใน Shared Drive
- แสดงเฉพาะไฟล์ที่คุณมีสิทธิ์เข้าถึง
- กดชื่อไฟล์เพื่อเปิดดูใน Viewer

> **เคล็ดลับ:** ค้นหาด้วยคำภาษาไทยได้ตามปกติ — ระบบรองรับ Full-Text Search ภาษาไทย

## 5. I-FAQ — คลังความรู้

### โครงสร้างหมวดหมู่

```
Level 1 (หมวดหมู่หลัก)
  └── Level 2 (หมวดหมู่ย่อย)
        └── Knowledge Item (บทความ/เอกสาร)
```

### วิธีเปิดบทความ

1. ดูที่ Sidebar ด้านซ้าย
2. กดหัวข้อ **Level 1** เพื่อขยายรายการ  
3. กดหัวข้อ **Level 2** (ถ้ามี) เพื่อขยายรายการย่อย  
4. กดชื่อ **บทความ** เพื่อเปิดอ่าน

### รูปแบบเนื้อหาบทความ

| รูปแบบ | คำอธิบาย |
|--------|-----------|
| **หน้าเว็บ** | เนื้อหา HTML แสดงในหน้าเดียว |
| **PDF** | ไฟล์ PDF เปิดใน PDF Viewer (ดู [หัวข้อ 7](#7-การดู-pdf)) |
| **วิดีโอ** | วิดีโอ YouTube หรือไฟล์ MP4 (ดู [หัวข้อ 8](#8-การดูวิดีโอ)) |
| **ผสม** | มีทั้งเนื้อหา HTML, PDF, และวิดีโอในบทความเดียว |

### Sidebar — การทำงาน

- **กด ▶** (ลูกศร) ที่ Level 1 เพื่อขยาย/ยุบรายการ
- **กด ▶** ที่ Level 2 เพื่อขยาย/ยุบบทความ
- บทความที่กำลังเปิดอยู่จะถูก **Highlight สีฟ้า** ใน Sidebar
- Sidebar จะ **จำตำแหน่งที่กางออก** ไว้แม้จะ Navigate ไปหน้าอื่นแล้วกลับมา

## 6. File Portal — คลังเอกสาร/ไฟล์

### ภาพรวม

File Portal เชื่อมต่อกับ **Shared Drive** ของบริษัทโดยตรง แสดงเฉพาะไฟล์ PDF และวิดีโอที่คุณมีสิทธิ์ตาม **AD Group**

> ⚠️ **สำคัญ:** คุณจะเห็นเฉพาะโฟลเดอร์/ไฟล์ที่ AD Group ของคุณได้รับสิทธิ์จาก Admin เท่านั้น

### วิธีใช้งาน File Portal

**ผ่าน Sidebar:**
1. ดูที่ Sidebar ด้านซ้าย หาส่วน **📁 File Portal**
2. กด **File Portal** เพื่อขยาย
3. กดชื่อโฟลเดอร์เพื่อดูไฟล์ข้างใน
4. กดชื่อไฟล์ (PDF หรือ VDO) เพื่อเปิด

**ผ่านการค้นหา:**
- ค้นหาชื่อไฟล์ใน Search แล้วกดผลลัพธ์ในส่วน "File Portal"

### สีของไฟล์ใน Sidebar

| สี | ประเภทไฟล์ |
|----|-----------|
| 🟠 ส้ม + ป้าย `PDF` | ไฟล์ PDF |
| 🟣 ม่วง + ป้าย `VDO` | ไฟล์วิดีโอ |

### Sidebar จำสถานะการกางโฟลเดอร์

เมื่อกางโฟลเดอร์ใดออกแล้วคลิกไฟล์เพื่อดู ระบบจะ **จำสถานะ** ว่าโฟลเดอร์ใดเปิดอยู่ เมื่อกลับมา Sidebar จะยังคงแสดงโฟลเดอร์เดิมที่กางออกไว้

## 7. การดู PDF

เมื่อกดเปิดไฟล์ PDF ระบบจะแสดง **PDF Viewer** ในหน้าเว็บ:

### ฟีเจอร์ PDF Viewer

| ปุ่ม | การทำงาน |
|------|----------|
| `◀ ▶` | เลื่อนหน้า ก่อน/หลัง |
| `🔍+` / `🔍-` | ขยาย/ย่อ |
| `↩` | หมุนหน้า |
| `⬇ Download` | ดาวน์โหลด PDF ลงเครื่อง |

> **หมายเหตุ:** บาง PDF อาจ Admin ตั้งค่าไม่ให้ Download ได้ (ขึ้นอยู่กับนโยบาย)

## 8. การดูวิดีโอ

เมื่อกดเปิดไฟล์วิดีโอ ระบบจะแสดง Video Player:

### ประเภทวิดีโอที่รองรับ

| ประเภท | คำอธิบาย |
|--------|-----------|
| **YouTube** | Embed ตรง ๆ ใน Viewer |
| **MP4 / WebM / OGG** | เล่นผ่าน Browser โดยตรง |

### การควบคุม

- ใช้ปุ่ม **Play/Pause**, **ปรับเสียง**, **Fullscreen** ตามปกติของ Browser
- สามารถ **กด Fullscreen** เพื่อดูแบบเต็มจอ

---

## 9. การออกจากระบบ

1. ดูที่มุมบนขวาของ Sidebar (ชื่อผู้ใช้และปุ่ม Logout)
2. กด **Logout** (หรือปุ่มออก)
3. ระบบจะ Clear session และกลับไปหน้า Login

> ระบบไม่มี Auto-logout ตามเวลา แต่ถ้าเครือข่ายหมด session อาจถูก expire — ให้ Login ใหม่

## 10. คำถามที่พบบ่อย

**Q: ทำไมฉันไม่เห็นโฟลเดอร์/ไฟล์บางอย่างใน File Portal?**  
A: ระบบแสดงเฉพาะไฟล์ที่ AD Group ของคุณมีสิทธิ์ ติดต่อ Admin เพื่อขอสิทธิ์เพิ่มเติม

**Q: ทำไม Search หาบทความไม่เจอ?**  
A: ลองค้นหาด้วยคำที่สั้นกว่า หรือใช้คำสำคัญ ถ้ายังหาไม่เจอแจ้ง Admin เพื่อตรวจสอบ

**Q: PDF เปิดไม่ได้ / โหลดช้า?**  
A: ตรวจสอบเครือข่าย หรือลอง Refresh หน้า ถ้ายังไม่ได้แจ้ง IT

**Q: ไฟล์ใน File Portal ไม่แสดงไฟล์ล่าสุด?**  
A: ระบบ Sync ไฟล์จาก Shared Drive ทุก 5 นาที รอสักครู่แล้วรีเฟรชหน้า

**Q: ลืมรหัสผ่าน?**  
A: รหัสผ่านเดียวกับ Windows — ติดต่อ IT เพื่อ Reset รหัสผ่าน AD
